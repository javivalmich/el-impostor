# El impostor

Juego del impostor para jugar en persona, cada uno con su móvil.

- Quien crea la partida escribe los nombres de los jugadores, elige cuántos impostores hay, si hay pista y las categorías.
- Los demás entran escaneando el QR o abriendo el enlace, y tocan su nombre.
- Cada uno mantiene pulsada su tarjeta para ver su palabra. Si la pantalla se pone roja, es el impostor.

Todo va en `index.html`: sin servidor, sin cuentas y sin base de datos. Cada móvil calcula la misma ronda a partir del enlace.

Para actualizar el juego, edita `index.html`, haz commit y push. GitHub Pages lo publica solo.
